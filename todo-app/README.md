# To-Do List App

A full-stack To-Do List application built with Node.js, Express, EJS, SQLite, HTML, CSS, and JavaScript.

## Features

- Create tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Persist tasks in SQLite
- Responsive, modern UI with completed task styling

## Project structure

- `app.js` - Express server and application setup
- `database.js` - SQLite database initialization
- `routes/` - Express route definitions
- `controllers/` - Route handlers and business logic
- `models/` - Database operations for tasks
- `views/` - EJS templates
- `public/` - Static CSS and JavaScript assets
- `data/` - SQLite database file storage

## Install and run

1. Open a terminal in `todo-app`.
2. Run `npm install`.
3. Start the app with `npm start`.
4. Open `http://localhost:3000` in your browser.
